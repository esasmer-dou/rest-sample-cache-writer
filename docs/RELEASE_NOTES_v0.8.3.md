# rest-sample-cache-writer 0.8.3

[English](RELEASE_NOTES_v0.8.3.md) | [Turkish](RELEASE_NOTES_v0.8.3.tr.md)

Builds with platform `4.9.0`, cache `0.9.2` and model `0.5.3`. This process does not start an HTTP server.

With sample PostgreSQL and Redis running, use `-Dsample.writer.run-once=true` to publish once. Verify the data with reader `0.8.3`.

For migration and setup, see [README](../README.md). JNI contracts and runtime defaults are unchanged. This update does not claim a new performance gain.
