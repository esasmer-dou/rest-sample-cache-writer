# 0.8.1 — Hazırlanan Düzeltme

[English](RELEASE_NOTES_v0.8.1.md) | [Türkçe](RELEASE_NOTES_v0.8.1.tr.md)

Henüz yayımlanmadı. Platform parent REST 4.8.1, cache 0.9.1 ile hizalanır.
Düzeltme ARM64 native manifestini günceller. İş kodu, property'ler ve native
dosyalar değişmez. ARM çalışma testi iddiası yoktur. Ortak model/utility 0.5.0,
Dubbo 0.9.0 olarak kalır.

Yayımdan sonra uygulamayı hizalanmış bağımlılıklarla yeniden derleyin. Eski
paketlerden native dosya kopyalamayın. Onay bekleyen bu düzeltmeden önce
README'de verilen 0.8.0 örnekleri yayımlanmış sürümün anlatımıdır.
