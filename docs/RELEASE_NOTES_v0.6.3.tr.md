# rest-sample-cache-writer 0.6.3

`0.6.3`, çalışan writer uygulamasını `rust-java-rest:4.4.1` ve `java-rust-cache:0.7.3` ile
hizalar. Paketlenen native runtime artık tam commit provenance bilgisini kullanır.

değişmez.
